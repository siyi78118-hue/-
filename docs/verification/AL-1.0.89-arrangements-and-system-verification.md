## 安排表完整链路

- 主脑在直接聊天、主动任务和朋友圈任务中始终接收 AL 综合 RP、虞栖核心预设、现有安排目录、当前角色日程和最近朋友圈语境。
- 主脑只能通过严格字段 `rolePlanOperationsJson` 提交创建、修改、取消、暂停、恢复或完成操作；非空操作必定升级到监督流程。
- 监督结果以结构化 `rolePlanOperations` 返回，不进入可见聊天正文或长期聊天记忆。
- Android 桥把结构化操作转换为一个隐藏 PLAN 部件；手机端只应用一次，并在本地持久化后再尝试云同步。
- 支持一次、每天、每周、每月和固定间隔；角色本人日程必须有持续时间。
- 支持编辑、立即执行、失败重试、暂停、恢复、取消、终态删除和变化历史。
- 一次性计划执行后完成；循环计划推进到下一次。Android 已推进的循环计划不会被手机落地逻辑再次推进。
- 原生失败会把对应计划标记为可重试失败态，不会永久停留在已领取状态。
- 云端不可用时本机快照仍先保存，Android 闹钟负责保护执行；恢复后可继续同步。

## 其他功能审计

| 功能 | 验证到的真实链路 |
| --- | --- |
| 直接聊天 | 手机可见历史先对账，再提交带真实说话者、当前批次边界、关系阶段、安排和朋友圈语境的协议 v2 请求。 |
| 时间流逝 | 对话中断时间与模型处理耗时分离；未结束话题在真实中断后按“现在”重新进入，结束话题不机械报时。 |

| 朋友圈 | 发布和互动由聊天主脑处理；公开动态不会混入私聊长期记忆，最近动态会进入后续语境。 |
| 支付 | 红包/转账卡片与正文决定原子对应；收下、拒收、待定均为结构化结果，批量发送前保持暂存。 |
| 证据记忆 | 事实带消息 ID、说话者和原话证据；未确认的手机回复不会提前进入检索，失败对账可重试且幂等。 |
| 关系阶段 | 长期 base 与冲突/冷却/修复 phase 分开；支持证据驱动的相邻升降级，不以单次争执或纯时间自动跳级。 |
| 离线生活 | 时间线跨重启推进，不重叠、不倒退；聊天可提出调整，但重大无依据事件会被拒绝。 |
| 恢复与去重 | LAN/云复投、超时重跑、迟到失败、手机回执和启动补偿均使用稳定身份，避免重复回复。 |
