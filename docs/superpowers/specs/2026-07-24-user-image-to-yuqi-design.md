# 用户向虞栖发送图片：设计规格

## 目标

用户可在虞栖私聊的“＋”面板选择手机图片，将图片作为一条待发送消息加入当前整消息批次；点击“发送结束”后，图片与同批文字一起交给聊天小g查看并回复。

## 范围

- 支持从手机相册选择一张图片。
- 支持单独发送图片，也支持图片与文字属于同一批整消息。
- 手机聊天页显示图片缩略图，保留发送状态、失败重试、删除及批次语义。
- 图片经过方向修正、缩放和 JPEG 压缩，单张传输数据受现有加密云信箱 512KB 密文限制约束。
- 聊天小g获得真实图片输入，并同时获得图片消息的文字占位说明。
- 记忆与上下文将一张图片气泡计为一条消息；图片不自动产生长期事实。

## 非目标

- 虞栖主动发送图片。
- 多图选择、拍照、图片编辑。
- 新增 R2 或另一套云端文件服务。
- 对图片进行独立 OCR、自动打标签或长期保存推断结果。

## 数据结构

图片消息沿用现有聊天消息对象，增加：

- `type: "image"`
- `imageData`: 压缩后的 `data:image/jpeg;base64,...`
- `imageMime: "image/jpeg"`
- `imageWidth`、`imageHeight`
- `imageBytes`
- `imageName`

桥接输入中的用户消息增加 `attachments` 数组；每个附件包含稳定附件编号、媒体类型、MIME、文件名及 data URL。运行时解码为任务专属临时文件，校验 MIME、大小和图片签名后，作为 Codex `localImage` 输入交给记忆小g、聊天小g和监督小g。任务结束后清理临时文件。

## 用户流程

1. 用户打开虞栖聊天页的“＋”，点击“图片”。
2. 系统选择图片、修正方向、缩放压缩并显示发送中的短提示。
3. 成功后图片气泡进入当前待发送批次；失败则不创建半成品消息，并给出可理解的错误。
4. 用户可以继续发送文字或图片。
5. 点击“发送结束”后，整个批次只创建一次回复任务。
6. 桥接将图片交给小g；虞栖结合图片与同批文字回复。

## 失败处理

- 非图片、读取失败、解码失败、图片过大：在手机端阻止发送并提示重新选择。
- 桥接解码或图片签名不合法：任务失败且保留原消息，可用现有“重新发送”重试。
- 网络差导致重复提交：沿用消息 ID、批次 ID 和 turn ID 去重，图片不产生第二次回复。
- 旧版运行时不支持图片：返回明确的版本不兼容原因，不把图片悄悄降级为空文字。

## 验收标准

- “＋”面板出现“图片”，可以选取并预览。
- 单图和图文混合批次均能成功触发一次回复。
- 小g能准确描述测试图片中的主要可见内容。
- 图片消息在聊天备份/恢复后仍可显示。
- 云信箱和局域网走同一附件协议。
- 原有文字、语音、引用、红包、转账、主动消息和朋友圈测试继续通过。
