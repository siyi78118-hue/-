# 云闹钟 KV 配额恢复设计

## 目标

修复 Cloudflare Workers KV 免费计划每日 1,000 次写入额度耗尽后，私聊与朋友圈云闹钟持续返回模糊 `400`、本地任务被回滚且反复刷日志的问题。

## 已确认根因

受控请求得到 Worker 原始响应：`KV put() limit exceeded for the day.`。当前 Worker 的任务、时间桶、事件日志和空闲 Cron 心跳都写入同一 KV 配额；异常任务风暴会耗尽当天写入额度。额度耗尽后 `/schedule` 在保存任务前失败，但网页端丢弃响应正文，只显示 HTTP 400。

## 设计

- Worker 将 KV 每日写入额度错误归类为 `KV_DAILY_WRITE_LIMIT`，返回 HTTP 429、北京时间次日 08:00 的 `retryAt`，并输出结构化控制台日志。
- 空闲 Cron 心跳从每 10 分钟降为每 60 分钟；例行成功事件不再写入 `meta:recentEvents`，降低正常运行的 KV 写入量。
- 网页端完整解析 Worker 错误正文并生成中文提示。
- 遇到 `KV_DAILY_WRITE_LIMIT` 时保留已创建的本地任务和原生快照，不回滚；记录暂停截止时间，暂停云端重试，额度重置后自动重新同步。
- 普通参数错误仍按原逻辑回滚，避免保存无效本地任务。

## 验收

- Worker 配额错误返回稳定的结构化错误码和重试时间。
- 连续 60 次空闲 Cron 最多写一次心跳。
- 软件显示“Cloudflare KV 今日写入额度已用完”而不是裸 `400`。
- 配额错误不会删除本地私聊或朋友圈任务，也不会在重置前反复请求云端。
- 全量测试、Android 构建、Worker 部署和软件内更新发布成功。
