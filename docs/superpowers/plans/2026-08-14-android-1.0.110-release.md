# Android 1.0.110 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Execute this release inline and preserve the existing dirty worktree; do not reset, checkout, or stage unrelated files.

**Goal:** Deliver a formally signed, cover-installable AL Android 1.0.110 APK containing the completed canonical messaging, quote/recovery, and proactive deadline stability fixes.

**Architecture:** Freeze the exact product diff, advance every release identity surface to 110, regenerate the Capacitor Android web assets, run the JavaScript and Android gates, then publish through the fixed-certificate GitHub Actions workflow. Download and independently verify the resulting APK before delivery.

**Tech Stack:** HTML/JavaScript, Node.js tests, Capacitor 8, Android Gradle, GitHub Actions REST API, Android build-tools (`aapt`, `apksigner`).

## Global Constraints

- Preserve all unrelated dirty and untracked user files.
- Do not stage or publish `zhaxian-workbench` deletions, private artifacts, temporary build directories, or user documents.
- Release identity is exactly `versionCode 110` and `versionName 1.0.110`.
- The final APK package is `com.siyi.al` and the signer SHA-256 is `5761277e3bdf4a64236c3bad569de6a07666581f643167d01e37f13e9e832b2b`.
- A debug, unsigned, or differently signed APK is not an acceptable deliverable.
